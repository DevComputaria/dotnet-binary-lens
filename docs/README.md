## Propósito

O CLR Lens é um analisador estático de performance e confiabilidade para assemblies .NET, com reescrita IL verificada como capacidade posterior e opt-in.

A documentação distingue explicitamente:

- prova estática;
- limite superior ou inferior;
- inferência;
- estimativa;
- medição runtime;
- heurística;
- desconhecido.
